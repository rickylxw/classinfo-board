# 📚 课程信息板 · Classinfo Board

一个本地运行的课程信息管理网站（**Vue 3 + Vite**，带 **Node 零依赖后端**），用来集中保存每门课的 **教学群、文件、DDL、作业要求** 等信息，并按 **数理基础类 / 专业类 / 思政类 / 通选类 / 体育类** 对课程分组。

登录后使用：首次进入（未登录）只看到只读欢迎页——没有任何数据、也不能修改；登录后数据自动云端同步，可多设备共用。

## 启动方式

**日常开发（推荐，需要两个终端）**

```bash
npm install
node backend/server.mjs   # 后端：账号 + 数据同步，端口 5174
npm run dev               # 前端：Vite，端口 5173（/api 自动代理到 5174）
```

浏览器打开 http://localhost:5173

**生产构建（长期本地使用）**

```bash
npm run build      # 产物输出到 dist/
node backend/server.mjs   # 后端 5174
node server.mjs    # 静态 + API 代理，监听 5173
```

> 端口保持 5173 不变：localStorage / IndexedDB 的数据按"协议+域名+端口"隔离，换端口浏览器会当成新站点、看不到旧数据。

## 账号与登录（ehall Cookie 验证）

- 顶栏「登录」→ 粘贴你的 ehall（ehall.seu.edu.cn）Cookie → 后端向「我的课表」接口发请求验证
- 验证通过后自动以返回的**学号**作为账号，本地课程数据自动备份/同步到后端（`backend/data/`）
- 云同步是**服务器权威**：服务端数据是唯一可信源，**每次变动（增删改、标完成、归档、状态切换）都立即发送请求上云**，不再本地暂存后批量推送；服务器按序合并后把权威状态强制下发回本机，localStorage 只是启动缓存。客户端**不能整体覆盖或删除云端数据**——删除走显式 id 白名单，登录时本机独有条目只增并入云端、随后整体以云端为准
- 登录后「拉取课表」对话框出现「⚡ 直接拉取」按钮：后端用保存的 Cookie 在服务端拉课表，无需再跑控制台脚本
- ehall Cookie 有效期有限（数小时到数天）；**设置应用密码后，日常登录只需「学号 + 密码」**，任何设备都不用再复制 Cookie（密码以 scrypt 单向哈希存服务器）
- 会话 30 天且**滑动续期**：只要正常使用就不会掉线；快捷登录凭证只在本机浏览器
- 首次进入（未登录）是只读欢迎页：不给任何示例数据、没有任何修改入口；登录后才有完整功能

Cookie 获取方法（登录对话框里也有图文步骤）：浏览器登录 ehall → F12 → Network → 刷新页面 → 点任意请求 → Request Headers 里复制 `cookie:` 整行值。

**快捷登录**：登录成功后浏览器会记住本次凭证，下次打开登录框直接点「⚡ 快捷登录」一键重试，不用重新复制；后端在你使用应用期间每 10 分钟对 ehall 做一次心跳保活，尽量延长凭证有效期。凭证失效（ehall 过期/改密/异地登录被踢）时快捷登录会明确提示，重新复制一次即可。退出登录会连同记住的凭证一起清除。

## 课程共享（课程负责人制）

- 在课程详情页点 **「📨 申请成为课程负责人」** → 管理员审核
- **通过后被任命为课程负责人**，获得该课程**共享板**的编辑权：添加/编辑/删除共享 DDL 与作业、上传/删除共享附件——全部**自动同步给同名同教师的每一位同学**
- 同学端在作业列表中直接看到共享作业（带「同步 · 来源」标记），可标记完成（**仅自己可见，永不互相同步**）、可复制为自己的可编辑作业；共享附件在「班级同步」卡片中下载
- **成员投稿（无需负责人）**：任何登录成员都能把 DDL/作业（「📤 投稿作业」或个人作业列表的 📤）和附件投稿到共享板；**课程负责人或管理员**均可审核——通过即上架同步全班，驳回则不入板；投稿人可在卡片里查看自己的待审状态；没有负责人的课程投稿由管理员代审（同步来源显示「管理员」）
- **一键投稿/发布**：成员可把自己已有的作业、文件一键投稿；负责人则是一键**直接发布**（跳过审核立即同步）
- **实时同步（SSE）**：共享板的作业/附件/教学群/投稿审核/负责人变更，任何一人操作后**即时推送**给所有在线的同课同学（实测毫秒级），前端自动重拉，不用手动刷新；个人课程数据的变更不广播（自己改的自己立即知道）
- **共享教学群（全班唯一一份）**：负责人（或管理员）在共享板里维护一份教学群信息（类型/群号/链接/备注），自动同步给全班；个人课程不再各自填写教学群，同学在课程页「👥 教学群」卡片查看/复制，需要改动就提交修改申请（经负责人/管理员审核后同步全班）
- **驳回是永久的**：负责人申请被驳回者无法重新申请该课程的负责人；若已有负责人，他人申请会提示已有负责人
- 管理员可**撤销负责人**（共享板数据保留，便于任命新负责人）；撤销后已上架内容仍同步给同课同学（来源显示「管理员」），期间的新投稿也可由管理员代审
- 已知限制：共享作业的要求里暂不支持内嵌图片（图片存个人空间，同学看不到），请用共享附件上传图片

## 管理员

- 后端**首次启动自动注册管理员**，账号密码打印在启动日志里（形如 `👑 已注册管理员账号: admin / xxxxxxxx`）；忘记密码删除 `backend/data/admin.json` 重启即可重置，也可用环境变量 `ADMIN_USER` / `ADMIN_PASS` 指定
- 登录对话框底部「管理员登录」→ 进入**独立的管理控制台**（不加载用户课程界面）：成员投稿审核（所有课程的待审投稿，通过/驳回）、负责人申请审核（通过并任命/驳回）、账号管理（列表/踢下线/删除）、全局统计
- 管理员会话与用户会话完全隔离：管理员 token 不能访问任何用户数据接口；**退出管理员自动恢复之前的用户登录**

## 登出与本地数据

- **退出登录会清空本机全部用户数据**（localStorage + IndexedDB 文件），云端保留，重新登录自动恢复
- 管理员切回用户登录不属于登出，数据保留

## 功能

- **课程管理**：名称、教师、学期、类别、颜色标签、课程备注
- **课程分类**：数理基础类 / 专业类 / 思政类 / 通选类 / 体育类（未选择则归入"未分类"），侧边栏按类别分组展示；要改类别列表，编辑 `src/store.js` 里的 `CATEGORIES` 一行即可
- **拉取课表（东南大学 ehall）**：顶栏「拉取课表」→ 按对话框内说明，在 ehall 页面控制台运行内置提取脚本（自动带登录态、零密码风险）→ 把复制的 JSON 粘贴回来 → 解析预览（同一门课多时段自动合并、教师 "null" 自动清洗、学期名自动转成 `2025-2026-1` 码）→ 逐行勾选并指定类别 → 批量导入。重复导入会按「课程名 + 学期」去重。导入的课程自动带上：教师、上课时间备注（周次/节次/教室）、教学群预设为「课程平台」并附 ehall 我的课表入口链接。接口字段依据见 `docs/seu-ehall-api-报告.md`
- **教学群**：群类型（QQ / 微信 / 钉钉 / 课程平台）、群号（一键复制）、加群链接、群备注
- **作业与 DDL**：标题、截止时间、完成状态打勾；仪表盘按截止时间排序，自动标出「已逾期 / 今天 / 3 天内 / 7 天内」
- **个人待办**：不隶属于任何课程的独立待办（交学费、取快递…），侧边栏「📌 个人待办」固定入口；添加作业时在课程下拉里选「📌 个人待办」即可；与课程作业一起出现在仪表盘汇总里，随账号云端同步
- **日程表**：侧边栏「📅 日程表」周视图——把课表导入的上课时间（周X · 第X-Y节 · 周次 · 教室）解析成网格课表，设置「学期第一周周一」后自动计算当前是第几教学周并按周次过滤（单/双周、跨周次都支持）；本周/上/下周切换；该周 DDL（课程作业 + 个人待办 + 班级同步）按天排列，点击直接标完成
- **DDL 归档**：作业/待办（含**班级同步的作业**，仅隐藏自己视角）完成后一键 📦 归档（或「🧹 归档已完成」批量收起），主列表只留要紧事；归档内容在侧边栏「🗃 归档」随时恢复（同步作业可恢复、自己的可彻底删除），不影响统计
- **深色模式**：顶栏 🌙/☀️ 一键切换，默认跟随系统，自动记忆
- **效率细节**：统计卡可点击筛选（点「已逾期」只看逾期）、`/` 键聚焦搜索、ESC 关闭弹层、窄屏侧边栏抽屉化、列表过渡动画、按钮防重复提交、点对话框遮罩即可关闭
- **作业要求富文本**：支持 **Markdown**（标题/列表/表格/代码块/引用等，GFM）与**内嵌 HTML**（经 DOMPurify 净化防 XSS）；编辑框可直接 **Ctrl+V 粘贴截图**或点「插入图片」，图片本体存 IndexedDB/云端、正文以 `cbimg://<id>` 引用，渲染时自动解析；带实时预览开关。分享的作业同样完整渲染
- **文件**：上传本地文件（保存在浏览器 IndexedDB，可随时下载回来）或添加在线链接（网盘、课程平台，可带提取码备注）
- **仪表盘**：课程总数 / 已逾期 / 7 天内截止 / 待办作业，全局待办列表
- **搜索**：顶栏搜索框，按课程名、教师、类别、作业标题、作业要求过滤
- **备份**：导出 / 导入 JSON 备份文件（包含上传的文件本体），换电脑、换浏览器可整体迁移

## 数据存放在哪里

| 内容 | 未登录 | 已登录（额外） |
|------|--------|----------------|
| 课程 / 作业 / 链接等结构化数据 | localStorage（登录后的启动缓存） | backend/data/accounts/<学号>.json（按账号独立文件，自动同步） |
| 上传的文件本体 | IndexedDB（本浏览器） | backend/data/files/<学号>/（按账号独立目录，自动备份） |
| ehall Cookie | — | backend/data/accounts/<学号>.json（仅本机，勿外传） |

多个同学可以共用同一个后端：数据按学号严格隔离，A 上传的文件 B 通过任何 id 都拿不到；后端每次同步只写当前账号自己的文件。

清理浏览器数据（"Cookie 和网站数据"）会删除本地数据；登录状态下云端仍有一份，重新登录即可恢复。请仍建议定期用「导出」做 JSON 备份。

## 技术栈与结构

Vue 3（`<script setup>` 组合式 API）+ Vite，无 UI 库、无路由、无状态库。

```
index.html                  Vite 入口（仅挂载点）
vite.config.js              端口 5173 + /api 代理到 5174
backend/server.mjs          零依赖后端：ehall Cookie 验证（学号即账号）、会话管理、
                             按账号隔离的数据同步与文件存储、服务端课表拉取（端口 5174）
                             启动时自动把旧版单文件 accounts.json 迁移为按账号文件
server.mjs                  生产静态服务器 + /api 代理（端口 5173）
src/
  main.js                   应用挂载
  style.css                 全局样式
  store.js                  响应式数据层：状态、自动持久化(watch → localStorage)、
                             IndexedDB 文件存取、增删改查、课表导入、登录后云同步
  api.js                    后端 API 客户端 + 会话状态（登录/数据/文件/课表）
  timetable.js              东南大学 ehall 课表解析 + 内置的控制台提取脚本
  utils.js                  纯工具函数（日期格式化、DDL 徽章、文件图标…）
  App.vue                   布局与对话框调度
  components/
    TopBar.vue              顶栏：标题 / 搜索 / 登录账号 / 导入导出 / 拉取课表 / 新建课程
    SideBar.vue             侧边栏：仪表盘入口 + 课程按类别分组
    Dashboard.vue           仪表盘：统计卡片 + 全局待办列表
    CourseDetail.vue        课程详情：作业与 DDL / 教学群 / 文件
    CourseDialog.vue        课程 新建/编辑 表单
    AssignmentDialog.vue    作业 新建/编辑 表单
    LinkDialog.vue          文件链接添加表单
    LoginDialog.vue         登录：粘贴 ehall Cookie 验证（含获取教程）
    TimetableDialog.vue     课表导入：登录直连拉取 / 提取脚本 / 粘贴 JSON / 预览 / 批量导入
    Toasts.vue              轻提示
```
